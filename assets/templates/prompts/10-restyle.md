# Starter Prompt 10 — Restyle an Existing Video
> Requires: vibe-motion-studio ≥ 1.1.0. Re-check this prompt on every minor release.

- **Use when:** reusing a finished video's script/audio in a new style or ratio.
- **Recommended:** any style, same or new ratio; reuse existing voice + TIMING.
- **Facts to prepare:** path to the existing project dir, target style, target ratio.

```text
Restyle this video with vibe-motion-studio as a separate project (never
overwrite the finished edition): source project [PATH], new style [STYLE],
[new ratio if changing, e.g. 9:16 portrait]. Reuse the existing voice-over and
TIMING; rebuild only the composition from the new style reference and its
Vertical section if portrait. Run the full Done-when checklist before finishing.
```

> The agent also understands Vietnamese — write the brief in Vietnamese if you prefer.
