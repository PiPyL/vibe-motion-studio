# Starter Prompt 06 — Stats / Data Story
> Requires: vibe-motion-studio ≥ 1.1.0. Re-check this prompt on every minor release.

- **Use when:** numbers carry the message (growth, benchmarks, results).
- **Recommended:** swiss editorial kinetic style, 16:9 landscape, 60–120 s,
  articulate curator voice.
- **Facts to prepare:** 3–5 numbers with sources, what each number proves,
  comparison baseline if any.

```text
Tell a data story with vibe-motion-studio. Style: swiss editorial kinetic,
16:9, about 90 seconds. Numbers: [N1 + source], [N2 + source], [N3 + source].
Odo counters on spoken digits, comparison matrix for baseline vs now, inverse
black drop on the biggest number. Facts: [PASTE SOURCES].
```

> The agent also understands Vietnamese — write the brief in Vietnamese if you prefer.
