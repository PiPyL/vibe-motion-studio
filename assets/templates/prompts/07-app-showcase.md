# Starter Prompt 07 — Mobile App Showcase
> Requires: vibe-motion-studio ≥ 1.1.0. Re-check this prompt on every minor release.

- **Use when:** showing an app's screens and flows on phones.
- **Recommended:** soft tactile clay style, 9:16 portrait, 45–90 s, cheerful voice.
- **Facts to prepare:** 3–4 key screens in order, the one action to highlight,
  store links.

```text
Showcase the [APP] mobile app with vibe-motion-studio. Style: soft tactile
clay, 9:16 portrait, about 60 seconds. Screens in order: [S1], [S2], [S3].
Bubbly pills per screen, toggle slides on the key action "[ACTION]", confetti
drop on the finale with store links. Voice: cheerful, Vietnamese captions.
```

> The agent also understands Vietnamese — write the brief in Vietnamese if you prefer.
