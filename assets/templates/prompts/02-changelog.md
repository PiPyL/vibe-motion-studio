# Starter Prompt 02 — Changelog / Release Notes Video
> Requires: vibe-motion-studio ≥ 1.1.0. Re-check this prompt on every minor release.

- **Use when:** turning release notes into a watchable update.
- **Recommended:** glass keynote style, 16:9 landscape, 60–120 s, English VO +
  Vietnamese captions.
- **Facts to prepare:** version number, list of changes grouped by
  feature/fix/breaking, links to changelog or PRs.

```text
Turn these release notes into a changelog video with vibe-motion-studio:
[PASTE NOTES OR CHANGELOG URL]. Style: glass keynote, 16:9, about 90 seconds.
One scene per change group, terminal-style list for fixes, calm outro with the
version number. English voice-over, Vietnamese captions.
```

> The agent also understands Vietnamese — write the brief in Vietnamese if you prefer.
