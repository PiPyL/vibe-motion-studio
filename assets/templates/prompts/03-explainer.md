# Starter Prompt 03 — Explainer (How It Works)

- **Use when:** explaining a concept, workflow or architecture simply.
- **Recommended:** soft tactile clay style, 16:9 landscape, 90–150 s, friendly voice.
- **Facts to prepare:** the 3–5 steps in order, one analogy if available,
  what the viewer should do at the end (CTA).

```text
Explain [TOPIC] with vibe-motion-studio as a friendly explainer. Style: soft
tactile clay, 16:9, about 120 seconds. Steps in order: [STEP 1], [STEP 2],
[STEP 3]. One clay card per step, toggle slides on confirmation words, warm
cream outro with CTA: [CTA]. English voice-over, Vietnamese captions. Facts:
[PASTE DOCS OR LINKS].
```

> The agent also understands Vietnamese — write the brief in Vietnamese if you prefer.
